## 1. アプリ概要・コンセプト

**どんなアプリか(一言で)：**  
壊れやすい卵を転がして、足場を渡りながらゴールのフライパンを目指す、Python製の2D横スクロールアクションゲームです(全3ステージ)。

**ターゲットユーザー・利用シーン：**  
キーボードだけで気軽に遊べる、短時間(1ステージ1〜2分)のアクションゲームを遊びたい人向け。

**一番のこだわり・アピールポイント：**  
- **卵の物理挙動**：卵型の凸多角形に、Pymunk(物理演算ライブラリ)の質量・重心・摩擦を設定しています。段差や傾斜での転がり方が変わり、回転は描画のごまかしではなく物理演算の結果そのものです。
- **操作感**：加速・減速・慣性があり、空中では操作がききにくくなります。ジャンプの高さは固定で、接地猶予時間(約0.1秒)で操作ミスを救済します。
- **ダメージの仕組み**：着地の速さ・壁への衝突・トゲを別々に判定し、同じ接触で二重にダメージが入らないようにしています。
- **チェックポイント**：位置・耐久度・トーストの取得状態を保存し、復活時にそれらを元に戻します(動く足場の位置も戻します)。
- すべて図形を描いて表現しており、画像素材は使っていません。サウンドもありません。

> 参考作品：Steam版「LOST EGG」のゲーム性(壊れやすい卵を操作してゴールを目指す)を参考にしています。プログラム・画像・音声・デザインはコピーせず、独自に作成しました。

## 3. 開発環境・起動手順

### 動作環境

- OS：Windows 10 以降
- 画面：1280×720 の固定サイズのウィンドウ
- 操作：キーボードのみ(マウスは使いません)

### 使用技術スタック

- 使用言語：Python 3.12(開発環境のバージョンは 3.12.10)
- フレームワーク・ライブラリ：
  - pygame 2.6.1(画面の描画・キー入力)
  - pymunk 7.3.1(物理演算)
  - pyinstaller 6.16.0(exeファイルの作成用。ゲームの実行には不要)
- エディタ：Visual Studio Code

### 開発環境の構築方法(Windows)

1. **Python をインストール**する。https://www.python.org/downloads/ から Python 3.12 をダウンロードし、インストーラーで **「Add python.exe to PATH」にチェック**を入れてインストールします。
2. PowerShell(またはVS Codeのターミナル)で、バージョンを確認します。

   ```powershell
   py -3.12 --version
   ```

3. **VS Code をインストール**し、拡張機能「Python」(Microsoft)を入れます。
4. プロジェクトのフォルダをVS Codeで開き、ターミナルで**仮想環境**(このプロジェクト専用のPython環境)を作って有効にします。

   ```powershell
   py -3.12 -m venv venv
   .\venv\Scripts\Activate.ps1
   ```

   「スクリプトの実行が無効」と出る場合は、一度だけ次を実行してからやり直します。

   ```powershell
   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
   ```

5. 必要なライブラリを `requirements.txt` からまとめてインストールします。

   ```powershell
   pip install -r requirements.txt
   ```

6. インストールされたか確認します。

   ```powershell
   pip list
   ```

### Pythonでの起動方法

```powershell
.\venv\Scripts\Activate.ps1
python main.py
```

開発用に、タイトル画面を飛ばして特定のステージから始めることもできます(例：ステージ2から)。

```powershell
python main.py 2
```

### LAN協力プレイ

同じLAN内で最大8人(ホストを含む)で遊べます。全員が同じバージョンのゲームを起動してください。

1. ホストPCでゲームを起動します。ターミナルに表示されたIPv4アドレスを参加者へ伝えます。

   ```powershell
   .\venv\Scripts\python.exe main.py --host
   ```

2. 参加するPCで、ホストのアドレスを指定して起動します。

   ```powershell
   .\venv\Scripts\python.exe main.py --join 192.168.1.5
   ```

   `192.168.1.5` はホストPCに表示されたアドレスへ置き換えます。

3. 操作は各PCのキーボードで行います(A/←、D/→、Space)。ステージ進行とポーズはホストが管理します。

通信にはTCPポート47652を使います。Windowsファイアウォールの確認が表示された場合は、プライベートネットワークでの通信を許可してください。インターネット越しの接続には対応していません。

### exeファイルの起動方法

`dist\LostEgg2D.exe` をダブルクリックします(Pythonのインストールは不要です。フォントもexeに含まれています)。  
初回起動時にWindowsの警告(SmartScreen)が出た場合は、「詳細情報」→「実行」を選びます。

### exeファイルの作成方法

仮想環境を有効にした状態で、次のコマンドを実行します(1行で実行してください)。

```powershell
pyinstaller --noconfirm --clean --onefile --windowed --name LostEgg2D --add-data "assets;assets" main.py
```

`dist\LostEgg2D.exe` ができます。`--add-data "assets;assets"` でフォントをexeに含めています。  
作り直すときは、`build` フォルダ、`dist` フォルダ、`LostEgg2D.spec` を削除してから実行してください。

### 操作方法

| キー | 操作 |
|---|---|
| A / ← | 左へ移動 |
| D / → | 右へ移動 |
| Space | ジャンプ(地面にいるときだけ) |
| Esc | ポーズ |

メニュー画面の操作：

| キー | 操作 |
|---|---|
| ↑ / ↓ | 項目を選ぶ |
| Enter | 決定 |
| Esc | 戻る・ポーズ解除 |

### ゲームのルール

- 卵には耐久度(最大100)があります。高い所から速く落ちたり、壁に強くぶつかったりすると減り、0になると割れてゲームオーバーです。ゆっくり触れるだけではダメージは受けません。
- トゲに触れると、固定で大きなダメージ(30)を受けます。ダメージのあと、短い無敵時間があります。
- 落下限界を超えて落ちると、耐久度に関係なくゲームオーバーです。
- トーストを取ると耐久度が10回復します(取らなくてもクリアできます)。
- 旗(チェックポイント)に触れると、その時点の状態が保存されます。ゲームオーバー後に「チェックポイントから再開」を選ぶと、保存した状態に戻ります(耐久度は100に戻りません)。
- フライパンに触れるとステージクリアで、約3秒後に次のステージへ進みます。

### デバッグ機能(開発用)

| キー | 動作 |
|---|---|
| **F3** | デバッグ表示の表示・非表示(通常は非表示)。卵の座標・速度・角度・耐久度・接地・接触・ダメージ結果・無敵時間・チェックポイント・カメラ・状態・ステージ番号と、当たり判定の赤線を表示します |
| R | ステージを最初からやり直す |
| K | 耐久度を0にする(ゲームオーバーの確認) |
| G | 落下限界の下へ移動する(落下ゲームオーバーの確認) |

### セーブデータ

- 保存するのは、**ステージのクリア状況だけ**です(解放状況は、クリア状況から決まります)。耐久度やトースト取得数などは保存しません。
- 保存場所：`%LOCALAPPDATA%\LostEgg2D\save.json`
  (エクスプローラーのアドレス欄に `%LOCALAPPDATA%\LostEgg2D` と入力すると開けます)
- **セーブデータの初期化方法**：ゲームを終了してから、上のフォルダにある `save.json` を削除します。次の起動時に、新規データで始まります。
- セーブデータが壊れていた場合は、初期状態で起動します。壊れたファイルは `save.json.corrupt-日時` という名前で同じフォルダに残り、エラーはログに記録されます。

### ログファイル

- 保存場所：`%LOCALAPPDATA%\LostEgg2D\logs\game.log`
- 起動、ステージ開始、ダメージ、トースト取得、チェックポイント、ゲームオーバー、再開、ステージクリア、セーブ・ロード、エラーが記録されます(毎フレームは記録しません)。約0.5MBごとに古いログへ回り、最大4ファイルまで残ります。

### フォントとライセンス

- フォント：**M PLUS Rounded 1c**(Regular / Bold)。`assets/fonts/` に同梱しています。
- 入手元：https://fonts.google.com/specimen/M+PLUS+Rounded+1c
- 著作権：Copyright 2016 The Rounded M+ Project Authors.
- ライセンス：**SIL Open Font License, Version 1.1**(同梱・再配布が可能です)。ライセンス全文は `assets/fonts/OFL.txt` にあります。

### ファイル構成

```text
プロジェクトフォルダ/
├── main.py              起動
├── config.py            調整できる数値(物理・ダメージなど)をまとめたファイル
├── game_manager.py      画面の状態(タイトル、プレイ中、ポーズなど)の管理
├── player.py            卵(物理ボディ・操作・描画)
├── physics.py           物理空間と衝突の判定
├── damage.py            耐久度とダメージ計算
├── stage.py             ステージ(足場・トースト・チェックポイント・ゴール)
├── moving_platform.py   動く足場
├── camera.py            カメラ
├── ui.py                フォントの読み込み、ゲージ、メニュー画面の描画
├── save_manager.py      セーブ・ロード
├── debug.py             デバッグ表示、ログ出力
├── stages/              ステージ1〜3の地形データ
├── assets/fonts/        同梱フォントとライセンス
├── requirements.txt     必要なライブラリ
└── README.md
```

### 困ったとき

- **起動しない・画面が出ない**：ログファイル(上記)の最後のほうに、エラーの内容が書かれています。
- **日本語が表示されない**：`assets/fonts/` に `MPLUSRounded1c-Regular.ttf` と `MPLUSRounded1c-Bold.ttf` があるか確認してください。
- **`pip install` でエラーが出る**：Python 3.12 を使っているか(`py -3.12 --version`)、仮想環境が有効か(行頭に `(venv)` が出ているか)を確認してください。
